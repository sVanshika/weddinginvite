# ASSET_GUIDE.md

# Asset Philosophy

Every asset should reinforce the illusion of a handcrafted luxury wedding invitation.

Prefer quality over quantity.

Every asset should have a clear purpose.

# Paper Textures

Purpose

Create realistic invitation surfaces.

Requirements

* High resolution
* Seamless
* Matte finish
* Cotton paper
* Handmade paper

Avoid

* Dirty textures
* Vintage stains
* Heavy creases

---

# Gold Assets

Purpose

Luxury accents.

Includes

* Gold foil textures
* Metallic gradients
* Decorative borders
* Dividers

Avoid

* Bright yellow
* Glitter
* Fake metallic effects

---

# Floral Assets

Style

* Watercolor
* Botanical
* Hand illustrated
* Soft colors

Usage

* Corners
* Borders
* Background accents

Avoid

* Cartoon flowers
* Clipart
* Oversaturated artwork

---

# Icons

Style

* Thin outline
* Minimal
* Elegant

Preferred Color

* Gold
* Charcoal

Avoid

* Filled icons
* Colorful icon packs

---

# Images

Photography Style

* Natural light
* Warm tones
* Editorial composition
* Authentic moments

Formats

* WebP
* AVIF

Use responsive image sizes.

---

# Decorative Elements

Allowed

* Wax seal
* Monogram
* Divider
* Botanical line art
* Gold ornaments
* Embossed frame

Avoid

* Heavy borders
* Decorative overload
* Excessive flourishes

---

# Audio

Optional

Background music

Requirements

* Soft piano
* Instrumental
* Ambient
* Romantic

Must

* Be muted by default
* Respect user preference

---

# Video

Only if necessary.

Allowed

* Short cinematic loops
* Soft bokeh
* Candlelight
* Floating particles

Avoid

* Large background videos
* Autoplay storytelling videos

---

# Animatable Assets

Preferred Formats

* SVG
* Lottie
* PNG (transparent)
* CSS shapes

Avoid animating large raster images.

---

# Optimization

Fonts

* Self-host
* Preload primary fonts

Images

* Lazy-load below the fold
* Compress
* Responsive sizes

Textures

* Reuse across components
* Cache aggressively

# Asset Checklist

Before adding any asset, verify:

* Matches the design system
* High resolution
* Optimized for web
* Mobile friendly
* Consistent with existing assets
* Has a clear purpose
* Enhances the invitation illusion
* Does not distract from the content
