# Section Goals

### 01. Arrival

* Create curiosity
* Minimal UI
* Focus on envelope

### 02. Envelope

* Floating invitation envelope
* User initiates interaction

### 03. Envelope Opening

* Scroll-controlled animation
* Reveal invitation

### 04. Invitation Reveal

* Card slides out
* Camera slowly zooms

### 05. Invitation Unfold

* Invitation opens into full layout
* Transition into storytelling

### 06. Welcome

* Couple names
* Invitation message
* Wedding date

### 07. Couple Story

* Short story
* Photos
* Timeline or scrapbook layout

### 08. Wedding Events

* Ceremony schedule
* Event cards
* Dates & timings

### 09. Venue

* Venue details
* Map
* Directions CTA

### 10. Gallery

* Wedding memories
* Scroll-based photo reveals

### 11. Countdown

* Days remaining
* Optional background animation

### 12. RSVP

* Guest form
* Confirmation
* Primary CTA

### 13. Closing

* Thank you
* Final message
* Gentle ending animation

---

# Navigation Rules

* No separate pages
* Continuous vertical experience
* Each section flows into the next
* Scroll is the primary navigation
* Optional floating progress indicator
* Optional music toggle
* No traditional navbar
