# DESIGN_SYSTEM.md

# Design Philosophy

The design system is inspired by handcrafted luxury wedding invitations rather than modern websites.

Every design decision should reinforce the illusion that the visitor is interacting with a premium printed invitation.

The visual language should feel:

* Elegant
* Warm
* Romantic
* Timeless
* Handcrafted
* Editorial

Avoid trends that may quickly become outdated.

---

# Design Principles

## 1. Material First

Every object should appear to be made from a real material.

Examples:

* Cotton paper
* Handmade paper
* Gold foil
* Wax
* Satin ribbon
* Pressed flowers
* Ink
* Embossed printing

Avoid plastic, glass-heavy, neon, or futuristic aesthetics.

---

## 2. White Space Creates Luxury

Never overcrowd a layout.

Every section should have generous breathing room.

The eye should naturally rest between elements.

Whitespace is not empty space—it is part of the design.

---

## 3. Editorial Composition

Layouts should resemble a luxury magazine or wedding album.

Use:

* Large margins
* Balanced asymmetry
* Elegant typography
* Strong visual hierarchy
* Carefully placed imagery

Avoid dashboard-like layouts or equal-sized cards.

# Background System

The website should never use flat colors.

Each background consists of:

* Base color
* Soft radial lighting
* Very subtle paper grain
* Delicate vignette
* Minimal depth noise

The user should almost not notice these layers—but they should feel them.

# Spacing Scale

Use an 8-point system.

XS = 8px

S = 16px

M = 24px

L = 40px

XL = 64px

2XL = 96px

3XL = 160px

4XL = 240px

Never reduce spacing simply to fit more content.

---

# Border Radius

Paper corners:

Very subtle.

4–8px.

Cards:

12px.

Buttons:

999px only when intentionally pill-shaped.

Avoid excessive rounding.

---

# Shadows

Shadows should imitate natural light.

Never use harsh black shadows.

Preferred shadow color:

Warm brown with low opacity.

Multiple soft shadows are preferred over one large shadow.

---

# Paper Treatment

Every paper element should include:

* Fine grain texture
* Slight edge darkening
* Soft lighting gradient
* Gentle drop shadow
* Natural imperfections

Paper should never appear perfectly flat.

---

# Gold Foil

Gold should behave like reflective foil.

Never use flat yellow.

Characteristics:

* Soft gradients
* Metallic highlights
* Slight shimmer during motion

Gold is reserved for:

* Names
* Decorative dividers
* Wax seal details
* Borders
* Icons

---

# Floral System

Flowers are supporting elements.

Never the primary focus.

Preferred style:

* Watercolor
* Hand illustrated
* Botanical
* Soft colors

Avoid:

* Cartoon flowers
* Bright saturated flowers
* Heavy floral borders

---

# Decorative Elements

Approved:

* Thin ornamental dividers
* Monograms
* Wax seals
* Embossed borders
* Fine line illustrations
* Minimal botanical drawings

Avoid:

* Heavy ornaments
* Clipart
* Stock wedding graphics
* Glitter effects

---

# Photography Style

Images should feel editorial.

Characteristics:

* Soft natural lighting
* Warm tones
* Authentic emotion
* Minimal posing
* Shallow depth of field

Avoid:

* Over-edited HDR
* Strong filters
* High saturation
* Artificial backgrounds

---

# Buttons

Buttons should feel like part of the invitation.

Preferred styles:

* Thin gold outline
* Warm ivory fill
* Soft shadow
* Gentle hover glow

Avoid:

* Bright gradients
* Glassmorphism
* Loud animations

Primary CTA example:

"Open Invitation"

"View Venue"

"Seal RSVP"

---

# Icons

Preferred icon style:

* Thin outline
* Gold or charcoal
* Minimal detail

Never use colorful icon packs.

---

# Responsive Philosophy

Design mobile first.

The invitation should feel perfect on portrait phones.

Tablet expands spacing.

Desktop adds breathing room and subtle depth.

Do not redesign layouts for desktop—only enhance them.

---

# Accessibility

Minimum contrast ratio for text.

Readable font sizes.

Keyboard navigation.

Reduced-motion support.

Decorative elements should never interfere with readability.

---

# Visual Consistency Rules

Every new section must answer these questions:

1. Does this still feel like part of the same invitation?
2. Would this look believable if printed?
3. Is the animation supporting the design?
4. Is there enough whitespace?
5. Is the typography doing most of the visual work?

If the answer to any question is "no," redesign the section before implementing it.

---

# Final Design Goal

The visitor should never think:

"I'm browsing a wedding website."

Instead, they should feel:

"I'm holding a beautifully crafted invitation that has somehow come to life."
